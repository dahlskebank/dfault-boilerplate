# _temp/

Disposable scratch: downloads, unzipped exports, screenshots, test output, one-off scripts, deploy batches (`_temp/deploy/`).
Anything in here may be deleted at any time. It is gitignored (all of it except this README), never built, never deployed.
Project-wide Grep/Glob skip it, so name the path when you search it.
Before a tracked file cites something in here, move that thing into `docs/` (see "Where files go" in CLAUDE.md).
